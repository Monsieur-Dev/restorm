# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately, either through GitHub's private vulnerability reporting
on this repository ("Security" tab → "Report a vulnerability") or by e-mail to
**contact@restorm.app** with `[security]` in the subject. Include the affected
version, a description of the issue and, when possible, steps to reproduce.

You will get an acknowledgement within 5 working days. Fixes ship in the next
release and are credited in the release notes unless you prefer to stay
anonymous.

## Scope

- the Restorm desktop application and its CLI/MCP packages (`restorm-cli`,
  `restorm-mcp`)
- the `restorm-action` GitHub Action

Issues in the hosted services (account, licensing, checkout) are handled by the
same contact address.

## Supported versions

Only the latest released version receives security fixes.
