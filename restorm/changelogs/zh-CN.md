# Changelog

## v1.2.0

**录制一个网页，把它的 API 变成请求。**

- **录制会话。** 一种新的侧边栏项目会在内置迷你浏览器中打开网页，并实时捕获它发出的每一次 API 调用——REST、GraphQL、gRPC-web 和 WebSocket——支持正则表达式白名单与黑名单、在地址栏上暂停和停止，运行期间还有一枚红色的“直播中”徽标。每个捕获的调用都与请求的响应一模一样地呈现（正文、信息、Cookie、图表）；调用的右键菜单可将其 url 加入某个名单，并可选择清理已捕获的内容。捕获只保留在内存中，由新的应用设置限定上限，绝不会触及您的项目文件。
- **推导路由（Pro）。** 一个按钮就能把捕获变成一棵由真实、可重放请求组成的文件夹树：变化的路径片段变为 `{{param}}` 路径参数，文件夹沿用静态前缀，gRPC-web 调用按服务归类，每个请求都根据最后一次成功的调用预填，并把捕获的调用放入其响应历史。再次推导时会合并——您的修改会被保留。
- **在您的 AI 助手中驾驭它。** 十个 MCP 工具可创建和配置会话、开始和停止录制、读取捕获并推导路由。
- **更丰富的“响应”标签页。** 图片现在直接内嵌显示，视频和音频可以播放，Markdown 会被渲染，代码编辑器根据 Content-Type 选择语言——并且随时有一个已翻译的“下载”按钮。从历史中重放的二进制响应不再显示其 base64。
- **长列表依然流畅。** 捕获列表（以及超过 400 行的侧边栏）只渲染屏幕上可见的部分。
- 包含录制会话的项目文件以 1.2 格式保存；较早版本的 Restorm 会请您先更新再打开这些文件。

## v1.1.4

**在 macOS 上连接您的 AI 助手——现在稳定可靠。**

- **已修复：macOS 上的 Claude Desktop 和 Cursor。** 连接 AI 助手时能加载 Restorm 的工具，但随后每次调用都会失败并提示“没有正在运行的实例”，即使 Restorm 已打开也是如此——应用和连接器在不同的临时文件夹里互相寻找。现在无论连接器由什么启动，它们都能稳定地相遇。
- **意大利语、波兰语和芬兰语的正式措辞。** 界面现在在这三种语言中以正式语气称呼您，与其余部分保持一致。
- **场景中的 Code 动作——更整洁，内置示例。** 脚本较长时 Code 节点不再被撑宽，其编辑器新增 **需要帮助吗？** 选项卡，按您所选语言展示可直接运行的示例（TypeScript、JavaScript、Python、Lua、Ruby、R、C#）。在编辑器打开时粘贴，不会再在画布上留下多余的 Code 节点。
- **发现导入 API 中的设计问题。** 导入 API 后——或重新打开文件时——Restorm 会悄悄检查每个 API 是否存在结构性问题（重复路由、缺失响应、与 Mock Server 冲突的路径……），在侧边栏用“!”标记它，并新增一个“问题”选项卡，列出每个问题以及确切受影响的路由，每条路由都可展开查看其文档。

## v1.1.3

**把您的 AI 助手连接到 Restorm。**

- **在应用中一键完成。** 状态栏的 MCP 菜单现在提供“将 Restorm 添加到您的 AI 助手”——为 Claude Code、Claude Desktop 和 Cursor 准备了可直接粘贴的配置，还有一键“添加到 Claude Code”。
- **或者一行命令，随处可用。** 用 `npx -y restorm-mcp` 让任意 MCP 客户端指向正在运行的 Restorm——桥接会自动找到它，无需复制端口或令牌。
- **为 Claude Code 提供的插件。** 运行 `/plugin marketplace add Monsieur-Dev/restorm`，然后安装 `restorm` 插件。

参见[连接您的 AI 助手](https://restorm.app/en/docs/outils/mcp/)。

## v1.1.2

**支持 OpenAPI 3.2。**

- **导入 OpenAPI 3.2 规范。** `QUERY` 方法、自定义动词（`additionalOperations`）、查询字符串参数和流式媒体类型都会作为可直接运行的请求导入。
- **浏览要导入的文件。** 导入对话框中的“浏览”按钮会打开原生文件选择器——不必再输入或拖拽路径。
- **大段粘贴的分屏视图。** 粘贴多行规范时，左侧打开代码编辑器，右侧显示预览，中间有可拖动的分隔条。
- **宽容的导入。** 含有几个损坏 `$ref` 的规范会尽可能导入所有路由，并用警告列出不得不跳过的内容。

修复：

- 导入无效或无法访问的规范会显示清晰的提示，而不是弹出崩溃报告对话框。
- 崩溃报告的详情视图可以再次滚动。
- 对话框背景不再模糊。

## v1.1.1

**API 设计器现在从侧边栏进行操作。**

- **您的模型、枚举和路由都集中在侧边栏。** 标签页内的三个列表消失了——模型（含其继承嵌套）、枚举和路由（分组及其路由）现在直接位于侧边栏的树中。右键即可重命名、添加子模型或子分组、克隆路由、生成 CRUD 或删除；拖动可重新排序或改换父级——绝不会跑到设计之外。每个页面现在只显示所选项的详情。
- **模型、枚举与路由的全局视图。** 每个部分的根节点现在会列出其下的所有内容——模型还新增了**图**标签页：一张展示继承与引用的类图。枚举会把取值显示在名称旁边。
- **统一的重命名入口。** 模型、枚举或路由都从大标题（铅笔）处重命名，名称为空时显示 **“<未命名>”**，让铅笔始终触手可及——名称不再在页面上出现两次。
- **校验错误指向具体项。** 当出现问题时（模型与枚举同名、引用了已不存在的对象等），该模型、枚举或路由顶部的提示会加以说明。
- **完整的面包屑。** 路径会映射侧边栏的完整层级——文件夹 › 设计 › 分区 › 分组 › 项——每一段都可点击。
- **多选并一次删除。** 选中多个模型、枚举或路由，确认后一次性删除。
- **一键复制或打开代码模板的源。** 在“</> Code”页面，将鼠标悬停在模板上会出现一个按钮用于复制其 URL 或路径，还有一个用于打开它——在浏览器中打开仓库，或对本地模板打开磁盘上的文件夹。
- **新路由一开始就有名称。** 从零创建的路由现在会获得一个默认名称，因此您可以立即重命名它。
- **预览标签页，就像您的编辑器一样。** 单击现在会在一个可复用的**预览**标签页中打开项目（其名称以斜体显示）；点击另一个项目会复用同一个标签页，而不是叠加一个新的。双击它、进行任意编辑，或运行一个请求，即可将其永久保留打开。可在设置 › 行为中关闭。
- **把您要一直打开的标签页固定住。** 右键点击标签页并将其固定：固定的标签页始终排在前面，能在“关闭其他”后保留，并按项目记住。
- **环境有了真正的详情视图。** 打开一个环境即可从其标题重命名、设置其图标和颜色并添加子环境——右键菜单现在还能连同环境的全部变量和子环境一起复制该环境。

修复：

- **选择代码模板会关闭库。** “使用”现在会直接把您带回 Code 页面。
- **文档生成不再因可选字段而失败。** 从模型或参数未设置“required”的设计生成文档，不再因模板错误而中断。
- **删除枚举会先确认。** 枚举现在与模型和路由一样会弹出确认。
- **侧边栏会显示您的选择。** 开启“侧边栏与活动标签页同步”后，选择或创建模型、枚举或路由时会展开其上级，使其在树中保持可见。
- **环境按钮在任何颜色上都保持可读。** 其文字现在会像运行按钮一样切换为深色或浅色，以在环境颜色上保持清晰。
- **中键点击可关闭已打开的文件。** 在侧边栏“已打开”列表中对某项中键点击会关闭其标签页——并且新增的“行为”设置可让您完全隐藏该面板。
- **从文档开始时用词更清晰。** 在导入的 API 文档中，按钮现在显示“从此文档创建新请求”。
- **Microsoft Store 版本可以正常登录。** 浏览器在您登录后回传的自定义协议回调现在已在 Store 包中声明，因此登录会顺利完成，而不再超时。

## v1.1.0

🎉 **Restorm 现在也是一款 API 设计器。**设计您的 API，同时横跨五种协议将其作为实时 mock 提供，并生成它的客户端——全程不离开应用，一切都在您自己的磁盘上。

- **可视化 API 设计器。**手动为您的 API 建模——模型、枚举（具名或内联）、路由、参数、具名示例、约束、标签与弃用——无需编写一行规范。
- **一键将其作为 mock 提供，同时横跨 5 种协议。**设计会变成一台服务器，同时以 HTTP、GraphQL、SOAP、OData 和 gRPC 作答。响应来自您的具名示例（或根据您的模型生成的逼真数据），并带有约束校验、模拟延迟和有状态模式。
- **开箱即用的客户端，自动生成。**在 mock 运行期间，Clients 部分会为每个已启用的协议创建真实、可运行的请求，指向 mock 的端点。一键即可打开一个请求并直击服务器——再也不必把您的 API 重新导入到别处去测试它。
- 使用所提供的模板以及您自己的自定义模板，从您的设计**生成代码**，代码在沙箱中渲染，只有在您确认后才写入磁盘。也可**导出描述符**（OpenAPI 及其他）。
- **导入时，请求体会预先填好**：GraphQL 会选中返回类型的标量字段，gRPC 会展开嵌套消息——请求可原样运行。

## v1.0.6

修复：

- **超大项目现在会以清晰的提示保存失败，而不再卡死。** 如果项目大到无法一次性写入磁盘（在导入异常庞大的 API 架构后可能发生），Restorm 会明确告知它过大无法保存，而不会崩溃或悄无声息地失败。
- **幕后错误报告更清晰。** 取消“另存为”对话框不再被记录为错误，导入失败现在会报告其真实原因——真正的问题因此更容易被发现和修复。

## v1.0.5

**Cookie jar——每个环境各有一罐 Cookie。**

- **每个环境都保留自己的 Cookie。**从两个环境分别登录您的开发 API 和生产 API，它们的会话绝不会串门——在一个环境中捕获的 Cookie 只会回传到那个环境。过期时间、`Path`、`Domain` 及其子域、`Secure`、`HttpOnly` 和 `SameSite` 如今都会得到遵循，而不再被丢弃。
- **认识 Cookie jar。**全新的工作台标签页——**视图 ▸ Cookie jar**——将每个环境的 Cookie 按域名分组，置于可折叠面板中列出：编辑某个值、删除某一条、清空某个域或整罐，也可以手动添加 Cookie。当您的请求设置 Cookie 时，它会实时刷新。
- **看清每个请求发送和收到了什么。**现在每个请求在 Response 和 Info 旁边都多了一个 **Cookies** 标签页，显示随该调用发送的 Cookie 以及收到的 Cookie——包括在重定向过程中设置、却从不会到达最终响应的 Cookie。它在您历史记录中的过往响应上同样可用。
- **Cookie 登录开箱即用。**返回 `Set-Cookie` 的请求会被捕获，并在随后受保护的调用中自动重放——在整个场景运行过程中也是如此，其中每一步都共享该环境的 Cookie 罐。
- **Cookie 会像浏览器那样持久保存。**带有过期时间的 Cookie 会按项目保存，并在您重新打开项目时重新加载；会话 Cookie 则会在您重启时被丢弃——与浏览器的做法别无二致。
- **不止于 REST。**GraphQL、SOAP、OData、JSON-RPC、tRPC 和 SSE 现在都能发送并存储 Cookie，而 WebSocket 则会在连接握手时携带它们。
- **Cookie 可以使用您的变量。**在手动添加的 Cookie 中输入 `{{token}}`，请求发出时它会依据当前活动环境进行解析。

修复：

- **自动保存现在也涵盖文件夹内的环境。**在自动保存模式下，添加或重命名子环境会立即保存——对于本就应当写入磁盘的更改，不再弹出“关闭前是否保存？”的提示。

## v1.0.4

**登录一次，所有窗口同步。**

- **您的账户现在会在窗口之间同步。** 在一个 Restorm 窗口中登录、退出或更换套餐，其他所有打开的窗口都会立即同步 — 无需重启，无需再次登录。在浏览器中完成登录后，确认信息现在会送达发起登录的那个窗口，即使同时打开了多个窗口。

修复：

- **代码节点在 Intel Mac 上恢复运行** — macOS Intel 版本附带了为 Apple Silicon 编译的 esbuild 二进制文件。
- **AppImage 启动器的"新建窗口"操作恢复打开窗口**，.deb/.rpm 软件包安装的 `restorm` 命令恢复可用。
- **Windows 启动更干净了** — 窗口现在通过应用协议加载，不再在每次启动时因内部错误而静默回退。

## v1.0.2

**您的 CLI/CI 令牌，无需离开应用。**

- **在 Restorm 中创建、查看和吊销令牌** — 面向 Pro 与 Enterprise 用户，通过标题栏的账户按钮。不必再为正在编写的流水线跑一趟仪表板。
- **令牌可以设置有效期。** 创建时选择 7 到 365 天，或像以往一样永不过期。过期令牌与已吊销令牌一样会被拒绝。
- **您的组织可以授权。** 管理员现在可以允许特定成员创建令牌，并单独开放审计日志的查看权限，而无需把对方设为管理员。
- **现在可以直接用 npm 安装 Restorm。** 先 `npm i -g restorm-cli`，再执行 `restorm`，应用会在 Linux、macOS 和 Windows 上直接启动，无需安装程序。构建只下载一次，经发布的校验和验证后缓存下来，流水线不会在每个作业中重复下载。

## v1.0.0

**Restorm 1.0 —— 本地优先的 API 客户端，正式发布。**

Restorm 是一款快速、离线优先的桌面客户端，可在所有主流协议上测试和驱动 API。

- **协议**：REST/HTTP、GraphQL、gRPC、WebSocket、SSE、SOAP、OData、MQTT、AMQP、STOMP、Kafka、Redis、tRPC、JSON-RPC。
- **场景**：可视化串联请求，分支/循环，提取并复用值，在 CI 中无界面运行。
- **环境与变量**：随处可用的 `{{handlebars}}`、类型化机密、按文件夹划分的环境。
- **导入/导出**：OpenAPI、Postman、Insomnia、HAR、WSDL、GraphQL SDL、OData EDMX、curl、代码导出。
- **Git 原生项目**：您的 `.restorm` 项目就是一个普通文件——对其进行版本管理、比较差异，并在应用内解决冲突。
- **本地优先且私密**：一切都在您的机器上运行；出站防火墙会拦截每一次外部调用。
- **跨平台**：Windows、macOS、Linux（.deb/.rpm/AppImage）+ npm。

免费的 Community 版，并为团队提供 Pro 与 Enterprise。
