# Changelog

## v1.0.6

修正：

- **超大專案現在會以清楚的提示儲存失敗，而不再卡住。** 如果專案大到無法一次寫入磁碟（在匯入異常龐大的 API 結構後可能發生），Restorm 會明確告知它過大無法儲存，而不會當機或默默失敗。
- **幕後的錯誤回報更清楚。** 取消「另存新檔」對話方塊不再被記錄為錯誤，匯入失敗現在會回報真正的原因——真正的問題因此更容易被發現與修正。

## v1.0.5

**Cookie jar——每個環境各有一罐 Cookie。**

- **每個環境都保留自己的 Cookie。**從兩個環境分別登入您的開發 API 和生產 API，它們的工作階段絕不會互相串門——在一個環境中擷取的 Cookie 只會回傳到那個環境。到期時間、`Path`、`Domain` 及其子網域、`Secure`、`HttpOnly` 和 `SameSite` 如今都會受到遵循，而不再被捨棄。
- **認識 Cookie jar。**全新的工作臺分頁——**檢視 ▸ Cookie jar**——將每個環境的 Cookie 依網域分組，置於可摺疊面板中列出：編輯某個值、刪除某一條、清空某個網域或整罐，也可以手動新增 Cookie。當您的請求設定 Cookie 時，它會即時重新整理。
- **看清每個請求送出與收到了什麼。**現在每個請求在 Response 與 Info 旁邊都多了一個 **Cookies** 分頁，顯示隨該呼叫送出的 Cookie 以及收到的 Cookie——包括在重新導向過程中設定、卻從不會到達最終回應的 Cookie。它在您歷史紀錄中的過往回應上同樣可用。
- **Cookie 登入開箱即用。**傳回 `Set-Cookie` 的請求會被擷取，並在隨後受保護的呼叫中自動重播——在整個情境執行過程中也是如此，其中每一步都共用該環境的 Cookie 罐。
- **Cookie 會像瀏覽器那樣持久保存。**帶有到期時間的 Cookie 會按專案儲存，並在您重新開啟專案時重新載入；工作階段 Cookie 則會在您重新啟動時被捨棄——與瀏覽器的做法別無二致。
- **不僅止於 REST。**GraphQL、SOAP、OData、JSON-RPC、tRPC 和 SSE 現在都能傳送並儲存 Cookie，而 WebSocket 則會在連線交握時攜帶它們。
- **Cookie 可以使用您的變數。**在手動新增的 Cookie 中輸入 `{{token}}`，請求送出時它會依據目前作用中的環境進行解析。

修正：

- **自動儲存現在也涵蓋資料夾內的環境。**在自動儲存模式下，新增或重新命名子環境會立即儲存——對於本就應當寫入磁碟的變更，不再彈出「關閉前是否儲存？」的提示。

## v1.0.4

**登入一次，所有視窗同步。**

- **您的帳戶現在會在視窗之間同步。** 在一個 Restorm 視窗中登入、登出或變更方案，其他所有開啟的視窗都會立即同步 — 無需重新啟動，無需再次登入。在瀏覽器中完成登入後，確認訊息現在會送達發起登入的那個視窗，即使同時開啟多個視窗。

修正：

- **程式碼節點在 Intel Mac 上恢復執行** — macOS Intel 版本內含為 Apple Silicon 編譯的 esbuild 二進位檔。
- **AppImage 啟動器的「新視窗」動作恢復開啟視窗**，.deb/.rpm 套件安裝的 `restorm` 指令恢復可用。
- **Windows 啟動更乾淨了** — 視窗現在透過應用程式協定載入，不再於每次啟動時因內部錯誤而靜默回退。

## v1.0.3

**沒有 FUSE，Restorm 也能在 CI 中執行。**

- **`restorm-cli` 現在可以在 CI 執行器與容器中運行。** Linux 建置改為解壓縮而非掛載，因此不再需要 Ubuntu 已停止提供的 FUSE。

## v1.0.2

**你的 CLI/CI 權杖，無需離開應用程式。**

- **在 Restorm 中建立、檢視與撤銷權杖** — 面向 Pro 與 Enterprise 使用者，透過標題列的帳戶按鈕。不必再為正在撰寫的流水線跑一趟儀表板。
- **權杖可以設定有效期。** 建立時選擇 7 到 365 天，或像以往一樣永不過期。過期的權杖與已撤銷的權杖一樣會被拒絕。
- **你的組織可以授權。** 管理員現在可以允許特定成員建立權杖，並單獨開放稽核日誌的檢視權限，而不必將對方設為管理員。
- **現在可以直接用 npm 安裝 Restorm。** 先執行 `npm i -g restorm-cli`，再輸入 `restorm`，應用程式會在 Linux、macOS 與 Windows 上直接啟動，不必經過安裝程式。建置只下載一次，通過已公布的總和檢查碼驗證後存入快取，管線不會在每個工作中重複下載。

## v1.0.1

**首個修補：側邊欄拖曳、分頁名稱與當機報告。**

- **在側邊欄移動項目不再讓應用程式壞掉。** 開啟迷你瀏覽器、設定或 MCP 記錄時，在側邊欄拖曳任何一列都會讓介面崩塌，只有重新啟動才能復原。
- **重新命名項目現在會更新每個開啟的分頁** — 包括分割窗格中的分頁，以及所有請求類型（gRPC、GraphQL、Redis 等）的分頁；先前它們會保留舊名稱直到重新開啟。
- **當機報告重新送達我們。** 即使開啟報告傳送，1.0.0 也悄悄什麼都沒送出：你遇到的當機沒有告訴我們任何事。
- **「程式語言」提示插圖重新顯示各語言標誌。**

## v1.0.0

**Restorm 1.0 —— 本地優先的 API 用戶端，正式發布。**

Restorm 是一款快速、離線優先的桌面用戶端，可在所有主流協定上測試並驅動 API。

- **協定**：REST/HTTP、GraphQL、gRPC、WebSocket、SSE、SOAP、OData、MQTT、AMQP、STOMP、Kafka、Redis、tRPC、JSON-RPC。
- **情境**：以視覺化方式串接請求，分支/迴圈，擷取並重複使用數值，在 CI 中以無介面模式執行。
- **環境與變數**：隨處可用的 `{{handlebars}}`、具型別的密鑰、依資料夾劃分的環境。
- **匯入/匯出**：OpenAPI、Postman、Insomnia、HAR、WSDL、GraphQL SDL、OData EDMX、curl、程式碼匯出。
- **Git 原生專案**：你的 `.restorm` 專案就是一個普通檔案——進行版本控制、比較差異，並在應用程式內解決衝突。
- **本地優先且私密**：一切都在你的電腦上執行；輸出防火牆會攔截每一次外部呼叫。
- **跨平台**：Windows、macOS、Linux（.deb/.rpm/AppImage）+ npm。

免費的 Community 版，並為團隊提供 Pro 與 Enterprise。
