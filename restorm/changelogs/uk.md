# Changelog

## v1.1.4

**Підключіть свого ШІ-асистента на macOS — тепер надійно.**

- **Виправлено: Claude Desktop і Cursor на macOS.** Підключення ШІ-асистента завантажувало інструменти Restorm, але потім кожен виклик завершувався помилкою «немає запущеного екземпляра», навіть коли Restorm відкритий — застосунок і конектор шукали одне одного в різних тимчасових теках. Тепер вони надійно знаходять одне одного, хоч би що запустило конектор.
- **Формальне звертання італійською, польською та фінською.** Інтерфейс тепер звертається до вас у формальному регістрі цими трьома мовами, узгоджено з рештою.
- **Дія Code у сценаріях — охайніша, із вбудованими прикладами.** Вузол Code більше не розтягується за довгого скрипту, а його редактор отримує вкладку **Потрібна допомога?** з готовим до запуску прикладом обраною вами мовою (TypeScript, JavaScript, Python, Lua, Ruby, R, C#). Вставлення за відкритого редактора більше не залишає випадковий вузол Code на полотні.
- **Виявляйте проблеми проєктування у ваших імпортованих API.** Після імпорту API — або під час повторного відкриття файлу — Restorm непомітно перевіряє кожен API на структурні проблеми (дубльовані маршрути, відсутні відповіді, шляхи, що конфліктують із Mock Server…), позначає його на бічній панелі знаком «!» та додає вкладку «Проблеми», яка перелічує кожну проблему й точно уражені маршрути, причому кожен маршрут можна розгорнути до його документації.

## v1.1.1

**Дизайнером API тепер керують із бічної панелі.**

- **Ваші моделі, enum'и та маршрути живуть у бічній панелі.** Три списки на вкладках зникають — моделі (з їхньою вкладеністю за успадкуванням), enum'и та маршрути (групи та їхні маршрути) тепер розташовані прямо в дереві бічної панелі. Клацніть правою кнопкою, щоб перейменувати, додати підмодель чи підгрупу, клонувати маршрут, згенерувати CRUD або видалити; перетягніть, щоб змінити порядок або батька — ніколи за межі дизайну. Кожна сторінка тепер показує лише деталі вибраного елемента.
- **Загальний огляд ваших моделей, енумів і маршрутів.** Кореневий вузол кожного розділу тепер перелічує все, що в ньому є — а Моделі отримують вкладку **Граф**: діаграму класів ваших моделей зі спадкуванням і посиланнями. Енуми показують свої значення поруч із назвою.
- **Єдине місце для перейменування.** Модель, енум чи маршрут перейменовується з великого заголовка (олівець), а порожня назва показує **«<без назви>»**, щоб олівець завжди був досяжний — назва більше не з'являється двічі на сторінці.
- **Помилки валідації вказують на елемент.** Коли щось не так — модель і енум з однаковою назвою, посилання на те, чого вже немає — примітка вгорі моделі, енума чи маршруту це пояснює.
- **Повний ланцюжок навігації.** Слід відображає всю ієрархію бічної панелі — теки › дизайн › розділ › група › елемент — і кожен сегмент клікабельний.
- **Виділіть кілька, видаліть за раз.** Виділіть кілька моделей, енумів чи маршрутів і видаліть їх за один раз, після підтвердження.
- **Скопіюйте або відкрийте джерело шаблону коду одним кліком.** На сторінці «</> Code» при наведенні на шаблон з'являється кнопка для копіювання його URL чи шляху та кнопка для його відкриття — репозиторій у браузері або тека на диску для локального шаблону.
- **Нові маршрути одразу мають назву.** Маршрут, створений з нуля, тепер отримує типову назву, тож ви можете одразу його перейменувати.
- **Вкладки попереднього перегляду, як у вашому редакторі.** Один клік тепер відкриває елемент у багаторазовій вкладці **попереднього перегляду** (назва курсивом); клік на інший елемент повторно використовує ту саму вкладку замість того, щоб додавати нову. Подвійний клік, будь-яке редагування або виконання запиту залишає її відкритою назавжди. Вимкніть це в Налаштування › Поведінка.
- **Закріплюйте вкладки, які тримаєте відкритими.** Клацніть вкладку правою кнопкою і закріпіть її: закріплені вкладки лишаються першими, переживають «закрити інші» й запам'ятовуються для кожного проєкту.
- **Середовища отримують повноцінний докладний вигляд.** Відкрийте середовище, щоб перейменувати його із заголовка, задати його піктограму й колір і додати підсередовище — а меню правого кліку тепер дублює середовище з усіма його змінними та підсередовищами.

Виправлення:

- **Вибір шаблону коду закриває бібліотеку.** «Використати» тепер повертає вас прямо на сторінку Code.
- **Генерація документації більше не падає на необов'язкових полях.** Генерація документації з дизайну, модель або параметр якого залишав «required» невстановленим, більше не зупиняється помилкою шаблону.
- **Видалення енума запитує підтвердження.** Енуми отримують таке саме підтвердження, як моделі й маршрути.
- **Бічна панель показує вибране.** Коли ввімкнено «синхронізувати бічну панель з активною вкладкою», вибір або створення моделі, енума чи маршруту розгортає їхніх батьків, щоб елемент залишався видимим у дереві.
- **Кнопка середовища залишається читабельною на будь-якому кольорі.** Її напис тепер перемикається на темний або світлий текст, щоб лишатися читабельним на кольорі середовища, як і кнопка виконання.
- **Клік середньою кнопкою закриває відкритий файл.** Клік середньою кнопкою по запису в списку «Відкриті» бічної панелі закриває його вкладку — а нове налаштування Поведінки дає змогу повністю сховати цю панель.
- **Чіткіше формулювання під час старту з документації.** У документації імпортованого API кнопка тепер має напис «Створити новий запит із цієї документації».
- **Вхід працює у версії з Microsoft Store.** Зворотний виклик власного протоколу, який браузер повертає після входу, тепер оголошено в пакеті Store, тож вхід завершується, а не спливає час очікування.

## v1.1.0

🎉 **Restorm тепер ще й конструктор API.** Спроєктуйте свій API, подавайте його як живий мок одразу на п'яти протоколах і згенеруйте його клієнтів — не залишаючи застосунку, усе на вашому власному диску.

- **Візуальний конструктор API.** Моделюйте свій API вручну — моделі, enum-и (іменовані чи вбудовані), маршрути, параметри, іменовані приклади, обмеження, теги та застарілості — не пишучи жодного рядка специфікації.
- **Подавайте його як мок, одним кліком, одразу на 5 протоколах.** Проєкт стає сервером, який відповідає в HTTP, GraphQL, SOAP, OData та gRPC одночасно. Відповіді надходять із ваших іменованих прикладів (або з реалістичних даних, згенерованих із ваших моделей), з валідацією обмежень, змодельованою затримкою та режимом зі станом.
- **Готові до запуску клієнти, згенеровані автоматично.** Поки мок працює, розділ Clients створює справжні, придатні до виконання запити для кожного увімкненого протоколу, спрямовані на ендпоінти мока. Один клік відкриває запит і б'є по серверу — більше не потрібно повторно імпортувати ваш API деінде, щоб його протестувати.
- **Згенеруйте код** зі свого проєкту за допомогою наданих шаблонів і власних кастомних, відрендерений у пісочниці та записаний на диск лише після вашого підтвердження. **Також експортуйте дескриптор** (OpenAPI та інші).
- **Під час імпорту тіла запитів заповнюються автоматично**: GraphQL обирає скалярні поля типу, що повертається, gRPC розгортає вкладені повідомлення — запит виконується як є.

## v1.0.5

**Cookie jar — окрема банка кук для кожного середовища.**

- **Кожне середовище зберігає власні куки.** Увійдіть до свого dev API та prod API з двох середовищ — і їхні сесії ніколи не перетнуться: кука, захоплена в одному, надсилається назад лише в ньому. Термін дії, `Path`, `Domain` та піддомени, `Secure`, `HttpOnly` і `SameSite` тепер враховуються, а не відкидаються.
- **Знайомтеся: Cookie jar.** Нова вкладка робочої області — **Вигляд ▸ Cookie jar** — перелічує куки кожного середовища, згруповані за доменом у згортних панелях: змініть значення, видаліть одну, очистіть домен чи всю банку або додайте куку вручну. Вона оновлюється наживо, щойно ваші запити встановлюють куки.
- **Бачте, що кожен запит надіслав і що отримав.** Кожен запит тепер має вкладку **Cookies** поряд із Response та Info, де показано куки, надіслані із викликом, і куки, отримані у відповідь — зокрема куки, встановлені під час перенаправлення, які ніколи не потрапляють до остаточної відповіді. Вона є й на минулих відповідях у вашій історії.
- **Вхід через куки просто працює.** Запит, що повертає `Set-Cookie`, захоплюється й автоматично відтворюється в наступних захищених викликах — зокрема впродовж виконання сценарію, де кожен крок спільно використовує банку кук середовища.
- **Куки зберігаються, як у браузері.** Куки з терміном дії зберігаються для кожного проєкту й завантажуються знову, коли ви його повторно відкриваєте; сеансові куки відкидаються під час перезапуску — точнісінько як зробив би браузер.
- **Не лише REST.** GraphQL, SOAP, OData, JSON-RPC, tRPC та SSE тепер надсилають і зберігають куки, а WebSocket переносить їх під час рукостискання з'єднання.
- **Куки можуть використовувати ваші змінні.** Введіть `{{token}}` у куку, додану вручну, і воно розкриється відповідно до активного середовища під час надсилання запиту.

Виправлення:

- **Автозбереження тепер охоплює середовища всередині тек.** У режимі автозбереження додавання або перейменування підсередовища зберігається одразу — більше жодного запиту «зберегти перед закриттям?» для зміни, яка й так мала опинитися на диску.

## v1.0.2

**Ваші токени CLI/CI — без виходу із застосунку.**

- **Створюйте, переглядайте та відкликайте токени в Restorm** — для користувачів Pro та Enterprise, з кнопки облікового запису в рядку заголовка. Більше жодних походів до панелі заради токена для конвеєра, який ви саме пишете.
- **Токени можуть спливати.** Оберіть строк дії під час створення: від 7 до 365 днів або без закінчення, як раніше. Прострочений токен відхиляється так само, як відкликаний.
- **Ваша організація може делегувати.** Адміністратор може дозволити конкретному учаснику створювати токени й окремо надати доступ до журналу аудиту, не роблячи його адміністратором.
- **Restorm тепер встановлюється з npm.** `npm i -g restorm-cli`, потім `restorm` — застосунок запускається в Linux, macOS і Windows без інсталятора. Збірка завантажується один раз, перевіряється за опублікованою контрольною сумою й зберігається в кеші, тож конвеєр більше не завантажує її на кожному завданні.

## v1.0.0

**Restorm 1.0 — local-first клієнт API вже доступний.**

Restorm — це швидкий десктопний клієнт, що працює насамперед офлайн, для тестування та керування API за всіма основними протоколами.

- **Протоколи**: REST/HTTP, GraphQL, gRPC, WebSocket, SSE, SOAP, OData, MQTT, AMQP, STOMP, Kafka, Redis, tRPC, JSON-RPC.
- **Сценарії**: візуально об'єднуйте запити в ланцюжки, розгалуження/цикли, витягуйте та повторно використовуйте значення, запускайте без інтерфейсу в CI.
- **Середовища та змінні**: `{{handlebars}}` усюди, типізовані секрети, середовища для кожної теки.
- **Імпорт/Експорт**: OpenAPI, Postman, Insomnia, HAR, WSDL, GraphQL SDL, OData EDMX, curl, експорт коду.
- **Проєкти, рідні для Git**: ваш проєкт `.restorm` — це звичайний файл; версіонуйте його, порівнюйте та вирішуйте конфлікти в застосунку.
- **Local-first і приватно**: усе працює на вашому комп'ютері; вихідний фаєрвол контролює кожен зовнішній виклик.
- **Кросплатформність**: Windows, macOS, Linux (.deb/.rpm/AppImage) + npm.

Безкоштовна редакція Community, а також Pro та Enterprise для команд.
