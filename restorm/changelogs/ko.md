# Changelog

## v1.0.0

**Restorm 1.0 — 로컬 우선 API 클라이언트, 출시.**

Restorm은 모든 주요 프로토콜에서 API를 테스트하고 실행하기 위한 빠른 오프라인 우선 데스크톱 클라이언트입니다.

- **프로토콜**: REST/HTTP, GraphQL, gRPC, WebSocket, SSE, SOAP, OData, MQTT, AMQP, STOMP, Kafka, Redis, tRPC, JSON-RPC.
- **시나리오**: 요청을 시각적으로 연결하고 분기/반복하며, 값을 추출해 재사용하고, CI에서 헤드리스로 실행합니다.
- **환경 및 변수**: 어디서나 `{{handlebars}}`, 형식이 지정된 시크릿, 폴더별 환경.
- **가져오기/내보내기**: OpenAPI, Postman, Insomnia, HAR, WSDL, GraphQL SDL, OData EDMX, curl, 코드 내보내기.
- **Git 네이티브 프로젝트**: `.restorm` 프로젝트는 일반 파일입니다 — 버전을 관리하고, 비교하고, 앱 안에서 충돌을 해결하세요.
- **로컬 우선 및 비공개**: 모든 것이 사용자의 컴퓨터에서 실행되며, 아웃바운드 방화벽이 모든 외부 호출을 통제합니다.
- **크로스 플랫폼**: Windows, macOS, Linux (.deb/.rpm/AppImage) + npm.

무료 Community 에디션, 팀을 위한 Pro 및 Enterprise 제공.
