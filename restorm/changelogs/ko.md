# Changelog

## v0.1.19

- Linux: 이제 AppImage가 안정적으로 시작되며, 강화된 샌드박스를 사용하는 배포판에서도 멈추지 않고 업데이트를 적용합니다.
- macOS: 이제 Apple Silicon과 함께 Intel용 빌드도 제공됩니다.

## v0.1.17

- 릴리스 노트가 이제 사용자의 언어로 표시됩니다.
- Linux, Windows, macOS 데스크톱 앱: 설치 프로그램에 Restorm의 아이콘, 이름, 세부 정보가 표시되며 앱이 사용자의 테마로 열립니다.

## v0.1.12

- 백그라운드 무음 자동 업데이트: Restorm이 시작 시와 주기적으로 업데이트를 확인하고, 백그라운드에서 다운로드하며, 다음 재시작 시 설치합니다. 업데이트마다 '새로운 기능' 알림이 표시됩니다.
- 수동 '업데이트 확인' 버튼과 설정의 자동 업데이트 전환.
