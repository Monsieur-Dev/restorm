# Changelog

## v1.1.0

🎉 **이제 Restorm은 API 디자이너이기도 합니다.** API를 설계하고, 다섯 개의 프로토콜에 동시에 라이브 목으로 제공하고, 클라이언트를 생성하세요 — 앱을 벗어나지 않고, 모두 자신의 디스크에서.

- **비주얼 API 디자이너.** API를 직접 모델링하세요 — 모델, enum(이름 붙인 것 또는 인라인), 라우트, 파라미터, 이름 붙인 예제, 제약 조건, 태그와 사용 중단 표시 — 사양을 단 한 줄도 작성하지 않고.
- **한 번의 클릭으로, 5개 프로토콜에 동시에 목으로 제공.** 설계는 HTTP, GraphQL, SOAP, OData, gRPC로 동시에 응답하는 서버가 됩니다. 응답은 이름 붙인 예제(또는 모델에서 생성된 현실적인 데이터)에서 나오며, 제약 조건 검증, 지연 시뮬레이션, 스테이트풀 모드를 갖추고 있습니다.
- **바로 실행 가능한 클라이언트, 자동 생성.** 목이 실행되는 동안 Clients 섹션은 활성화된 각 프로토콜에 대해 목의 엔드포인트를 향한 실제 실행 가능한 요청을 만듭니다. 한 번의 클릭으로 요청을 열고 서버를 호출합니다 — API를 테스트하려고 다른 곳에 다시 가져올 필요가 더 이상 없습니다.
- 제공된 템플릿과 직접 만든 커스텀 템플릿을 사용해 설계로부터 **코드를 생성하세요**. 코드는 샌드박스에서 렌더링되며, 확인한 후에만 디스크에 기록됩니다. **디스크립터**(OpenAPI 등)도 **내보낼 수 있습니다**.
- **가져올 때 요청 본문이 미리 채워집니다**: GraphQL은 반환 타입의 스칼라 필드를 선택하고, gRPC는 중첩된 메시지를 펼칩니다 — 요청이 그대로 실행됩니다.

## v1.0.6

수정:

- **매우 큰 프로젝트가 이제 멈추는 대신 명확한 메시지와 함께 저장에 실패합니다.** 프로젝트가 한 번에 디스크에 기록하기에 너무 커지면(비정상적으로 큰 API 스키마를 가져온 뒤에 발생할 수 있습니다) Restorm이 충돌하거나 조용히 실패하지 않고 저장하기에 너무 크다고 분명히 알려줍니다.
- **보이지 않는 곳에서의 오류 보고가 더 명확해졌습니다.** '다른 이름으로 저장' 대화상자를 취소해도 더 이상 오류로 기록되지 않으며, 실패한 가져오기가 이제 실제 원인을 보고합니다 — 그래서 진짜 문제를 더 쉽게 찾아 고칠 수 있습니다.

## v1.0.5

**Cookie jar — 환경마다 하나의 쿠키 저장소를.**

- **모든 환경이 각자의 쿠키를 유지합니다.** 두 개의 환경에서 각각 개발 API와 프로덕션 API에 로그인해도 세션이 서로 섞이지 않습니다. 한 환경에서 수집한 쿠키는 오직 그 환경에서만 다시 전송됩니다. 이제 만료 시간, `Path`, `Domain` 및 하위 도메인, `Secure`, `HttpOnly`, `SameSite`가 버려지지 않고 그대로 적용됩니다.
- **Cookie jar를 소개합니다.** 새로운 워크벤치 탭 **보기 ▸ Cookie jar** 는 모든 환경의 쿠키를 도메인별로 묶어 접을 수 있는 창에 나열합니다. 값을 편집하고, 하나를 삭제하고, 도메인이나 저장소 전체를 비우거나, 직접 쿠키를 추가할 수 있습니다. 요청이 쿠키를 설정하면 실시간으로 새로 고쳐집니다.
- **각 요청이 무엇을 보내고 받았는지 확인하세요.** 이제 모든 요청에는 응답과 정보 옆에 **Cookies** 탭이 생겨, 호출과 함께 보낸 쿠키와 되돌려 받은 쿠키를 보여 줍니다. 최종 응답에는 결코 닿지 않는, 리다이렉트에서 설정된 쿠키까지 포함합니다. 기록에 있는 과거 응답에서도 이용할 수 있습니다.
- **쿠키 로그인이 그대로 동작합니다.** `Set-Cookie`를 반환하는 요청은 수집되어 이후의 보호된 호출에서 자동으로 다시 전송됩니다. 시나리오 실행 중에도 마찬가지이며, 모든 단계가 환경의 저장소를 공유합니다.
- **쿠키가 브라우저처럼 유지됩니다.** 만료 시간이 있는 쿠키는 프로젝트마다 저장되어 다시 열 때 불러오고, 세션 쿠키는 다시 시작할 때 사라집니다 — 브라우저와 똑같이 동작합니다.
- **REST 그 이상.** 이제 GraphQL, SOAP, OData, JSON-RPC, tRPC, SSE 모두 쿠키를 주고받고 저장하며, WebSocket은 연결 핸드셰이크에서 쿠키를 함께 전달합니다.
- **쿠키에 변수를 사용할 수 있습니다.** 직접 추가하는 쿠키에 `{{token}}`을 입력하면 요청이 나갈 때 활성 환경을 기준으로 값이 확인됩니다.

수정:

- **이제 자동 저장이 폴더 안의 환경까지 포함합니다.** 하위 환경을 추가하거나 이름을 바꾸면 자동 저장 모드에서 곧바로 저장됩니다 — 이미 디스크에 반영되어야 할 변경에 대해 더 이상 "닫기 전에 저장하시겠습니까?"라고 묻지 않습니다.

## v1.0.4

**한 번의 로그인 — 모든 창이 따라옵니다.**

- **이제 계정이 창 사이를 따라다닙니다.** 하나의 Restorm 창에서 로그인, 로그아웃 또는 플랜 변경을 하면 열려 있는 다른 모든 창이 즉시 이를 반영합니다 — 재시작도, 두 번째 로그인도 필요 없습니다. 또한 브라우저에서 로그인을 완료하면 여러 창이 열려 있어도 확인이 이를 요청한 창에 도착합니다.

수정:

- **Intel Mac에서 코드 노드가 다시 시작됩니다** — macOS Intel 빌드에 Apple Silicon용으로 컴파일된 esbuild 바이너리가 포함되어 있었습니다.
- **AppImage 런처의 "새 창" 동작이 다시 창을 열고**, .deb/.rpm 패키지가 설치하는 `restorm` 명령이 다시 작동합니다.
- **Windows 시작이 깔끔해졌습니다** — 이제 창이 앱 프로토콜을 통해 로드되며, 실행할 때마다 내부 오류 후 조용히 대체 방식으로 전환되지 않습니다.

## v1.0.3

**FUSE 없이도 CI에서 Restorm이 돌아갑니다.**

- **이제 `restorm-cli`가 CI 러너와 컨테이너에서 동작합니다.** Linux 빌드를 마운트하지 않고 풀어서 실행하므로, Ubuntu가 더는 제공하지 않는 FUSE가 필요 없습니다.

## v1.0.2

**CLI/CI 토큰을 앱에서 바로 관리하세요.**

- **Restorm에서 토큰을 만들고, 보고, 취소하세요** — Pro 및 Enterprise 사용자용, 제목 표시줄의 계정 버튼에서. 지금 작성 중인 파이프라인용 토큰 때문에 대시보드를 오갈 필요가 없습니다.
- **토큰에 유효 기간을 줄 수 있습니다.** 만들 때 7~365일 또는 기존처럼 만료 없음을 고르세요. 만료된 토큰은 취소된 토큰과 똑같이 거부됩니다.
- **조직에서 권한을 위임할 수 있습니다.** 관리자는 특정 구성원에게 토큰 생성을 허용하고, 별도로 감사 로그 열람도 허용할 수 있습니다. 관리자로 만들 필요가 없습니다.
- **이제 npm에서 Restorm을 바로 설치합니다.** `npm i -g restorm-cli` 후 `restorm`을 실행하면 Linux, macOS, Windows에서 설치 프로그램 없이 앱이 시작됩니다. 빌드는 한 번만 내려받아 공개된 체크섬으로 검증한 뒤 캐시에 보관하므로, 파이프라인이 작업마다 다시 내려받지 않습니다.

## v1.0.0

**Restorm 1.0 — 로컬 우선 API 클라이언트, 출시.**

Restorm은 모든 주요 프로토콜에서 API를 테스트하고 실행하기 위한 빠른 오프라인 우선 데스크톱 클라이언트입니다.

- **프로토콜**: REST/HTTP, GraphQL, gRPC, WebSocket, SSE, SOAP, OData, MQTT, AMQP, STOMP, Kafka, Redis, tRPC, JSON-RPC.
- **시나리오**: 요청을 시각적으로 연결하고 분기/반복하며, 값을 추출해 재사용하고, CI에서 헤드리스로 실행합니다.
- **환경 및 변수**: 어디서나 `{{handlebars}}`, 형식이 지정된 시크릿, 폴더별 환경.
- **가져오기/내보내기**: OpenAPI, Postman, Insomnia, HAR, WSDL, GraphQL SDL, OData EDMX, curl, 코드 내보내기.
- **Git 네이티브 프로젝트**: `.restorm` 프로젝트는 일반 파일입니다 — 버전을 관리하고, 비교하고, 앱 안에서 충돌을 해결하세요.
- **로컬 우선 및 비공개**: 모든 것이 사용자의 컴퓨터에서 실행되며, 아웃바운드 방화벽이 모든 외부 호출을 통제합니다.
- **크로스 플랫폼**: Windows, macOS, Linux (.deb/.rpm/AppImage) + npm.

무료 Community 에디션, 팀을 위한 Pro 및 Enterprise 제공.
