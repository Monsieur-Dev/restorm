# Changelog

## v1.2.0

**웹 페이지를 기록하고, 그 API를 요청으로 받으세요.**

- **기록 세션.** 사이드바의 새로운 항목 유형이 내장 미니 브라우저에서 웹 페이지를 열고, 페이지가 수행하는 모든 API 호출 — REST, GraphQL, gRPC-web, WebSocket — 을 실시간으로 캡처합니다. 정규 표현식 허용 목록과 차단 목록, 주소 표시줄에서의 일시 중지와 중지, 실행 중에는 빨간 “방송 중” 배지가 함께합니다. 캡처된 각 호출은 요청의 응답과 똑같이 읽힙니다(본문, 정보, 쿠키, 그래프). 호출의 컨텍스트 메뉴에서 url을 목록에 추가할 수 있고, 이미 캡처된 것을 선택적으로 정리할 수도 있습니다. 캡처는 메모리에만 남으며, 새 앱 설정으로 상한이 정해지고, 프로젝트 파일은 절대 건드리지 않습니다.
- **경로 추론(Pro).** 버튼 하나로 캡처가 다시 실행할 수 있는 실제 요청의 폴더 트리가 됩니다. 달라지는 경로 세그먼트는 `{{param}}` 경로 매개변수가 되고, 폴더는 고정 접두사를 따르며, gRPC-web 호출은 서비스별로 정리되고, 각 요청은 마지막으로 성공한 호출로 미리 채워지며 캡처된 호출은 응답 기록에 들어갑니다. 다시 추론하면 병합됩니다 — 수정한 내용은 유지됩니다.
- **AI 어시스턴트에서 제어하십시오.** 열 개의 MCP 도구가 세션을 만들고 설정하며, 기록을 시작하고 중지하고, 캡처를 읽고 경로를 추론합니다.
- **더 풍부한 응답 탭.** 이제 이미지는 인라인으로 표시되고, 동영상과 오디오는 재생되며, Markdown은 렌더링되고, 코드 편집기는 Content-Type에서 언어를 고릅니다 — 번역된 다운로드 버튼도 항상 준비되어 있습니다. 기록에서 다시 실행한 바이너리 응답은 더 이상 base64를 표시하지 않습니다.
- **긴 목록도 빠르게.** 캡처 목록(그리고 400행을 넘는 사이드바)은 화면에 보이는 부분만 렌더링합니다.
- 기록 세션이 포함된 프로젝트 파일은 형식 1.2로 저장됩니다. 이전 버전의 Restorm에서는 열기 전에 업데이트하라는 안내가 표시됩니다.

## v1.1.4

**macOS에서 AI 어시스턴트를 연결하세요 — 이제 안정적으로.**

- **수정됨: macOS의 Claude Desktop과 Cursor.** AI 어시스턴트를 연결하면 Restorm의 도구는 불러왔지만 이후 모든 호출이 “실행 중인 인스턴스 없음”으로 실패했습니다. Restorm이 열려 있어도 마찬가지였는데, 앱과 커넥터가 서로 다른 임시 폴더에서 서로를 찾고 있었기 때문입니다. 이제 무엇이 커넥터를 실행했든 안정적으로 서로를 찾습니다.
- **이탈리아어, 폴란드어, 핀란드어의 격식체 표현.** 이제 이 세 언어에서 인터페이스가 나머지와 마찬가지로 격식체로 표현합니다.
- **시나리오의 Code 액션 — 더 깔끔하게, 예제 내장.** 스크립트가 길어도 Code 노드가 더 이상 늘어나지 않으며, 편집기에 **도움이 필요하신가요?** 탭이 추가되어 선택한 언어로 바로 실행할 수 있는 예제를 보여 줍니다(TypeScript, JavaScript, Python, Lua, Ruby, R, C#). 편집기가 열린 상태에서 붙여넣어도 캔버스에 불필요한 Code 노드가 생기지 않습니다.
- **가져온 API의 설계 문제를 찾아보세요.** API를 가져온 뒤 — 또는 파일을 다시 열 때 — Restorm은 각 API를 구조적 문제(중복 라우트, 응답이 없는 라우트, Mock Server가 예약한 경로와 충돌하는 경로 등)에 대해 조용히 검사하고, 사이드바에 “!” 표시를 달며, 각 문제와 정확히 영향을 받는 라우트를 나열하는 “문제” 탭을 추가합니다. 각 라우트는 해당 문서로 펼칠 수 있습니다.

## v1.1.2

**OpenAPI 3.2 지원.**

- **OpenAPI 3.2 사양 가져오기.** `QUERY` 메서드, 사용자 지정 동사(`additionalOperations`), 쿼리 문자열 매개변수, 스트리밍 미디어 유형이 바로 실행 가능한 요청으로 가져와집니다.
- **가져올 파일 찾아보기.** 가져오기 대화상자의 찾아보기 버튼이 네이티브 파일 선택기를 엽니다 — 더 이상 경로를 입력하거나 끌어놓을 필요가 없습니다.
- **큰 붙여넣기를 위한 분할 보기.** 여러 줄 사양을 붙여넣으면 왼쪽에 코드 편집기, 오른쪽에 미리보기가 열리고 그 사이에 드래그 가능한 구분선이 표시됩니다.
- **관대한 가져오기.** 깨진 `$ref`가 몇 개 있는 사양도 가능한 모든 라우트를 가져오고 건너뛴 항목을 경고로 보여줍니다.

수정 사항:

- 유효하지 않거나 접근할 수 없는 사양을 가져오면 크래시 보고서 대화상자를 여는 대신 명확한 메시지를 표시합니다.
- 크래시 보고서의 상세 보기가 다시 스크롤됩니다.
- 대화상자 배경이 더 이상 흐려지지 않습니다.

## v1.1.1

**이제 API 디자이너를 사이드바에서 조작합니다.**

- **모델, enum, 라우트가 사이드바에 자리 잡습니다.** 탭 안의 세 목록이 사라지고, 모델(상속 중첩 포함), enum, 라우트(그룹과 해당 라우트)가 이제 사이드바 트리에 바로 놓입니다. 마우스 오른쪽 버튼으로 이름 변경, 하위 모델이나 하위 그룹 추가, 라우트 복제, CRUD 생성, 삭제를 할 수 있고, 드래그로 순서를 바꾸거나 부모를 옮길 수 있습니다——절대 디자인 밖으로 나가지는 않습니다. 각 페이지는 이제 선택한 항목의 세부 정보만 표시합니다.
- **모델·열거형·라우트를 한눈에.** 이제 각 섹션의 루트 노드가 그 아래 내용을 모두 나열하며, 모델에는 **그래프** 탭이 추가됩니다. 상속과 참조를 그린 클래스 다이어그램입니다. 열거형은 값을 이름 바로 옆에 표시합니다.
- **이름 변경은 항상 한곳에서.** 모델·열거형·라우트는 큰 제목(연필)에서 이름을 바꾸며, 이름이 비어 있으면 **“<이름 없음>”**로 표시되어 연필에 항상 손이 닿습니다 — 이름이 페이지에 두 번 표시되지 않습니다.
- **검증 오류가 항목을 가리킵니다.** 무언가 잘못되면(모델과 열거형이 같은 이름, 더 이상 존재하지 않는 것에 대한 참조 등) 해당 모델·열거형·라우트 상단의 알림이 설명합니다.
- **완전한 이동 경로.** 경로가 사이드바 전체 계층(폴더 › 디자인 › 섹션 › 그룹 › 항목)을 반영하며 각 구간을 클릭할 수 있습니다.
- **여러 개 선택, 한 번에 삭제.** 여러 모델·열거형·라우트를 선택해 확인 후 한 번에 삭제합니다.
- **코드 템플릿의 소스를 한 번의 클릭으로 복사하거나 엽니다.** "</> Code" 페이지에서 템플릿 위에 마우스를 올리면 URL이나 경로를 복사하는 버튼과 여는 버튼이 나타납니다——브라우저에서 저장소를, 로컬 템플릿이면 디스크의 폴더를 엽니다.
- **새 라우트가 이름을 가지고 시작합니다.** 처음부터 만든 라우트에 이제 기본 이름이 붙으므로 바로 이름을 바꿀 수 있습니다.
- **에디터처럼 미리보기 탭.** 한 번 클릭하면 이제 항목이 재사용 가능한 **미리보기** 탭에서 열립니다(이름은 기울임꼴로 표시). 다른 항목을 클릭하면 새 탭을 쌓지 않고 같은 탭을 재사용합니다. 더블클릭하거나 무언가를 편집하거나 요청을 실행하면 계속 열린 상태로 유지됩니다. 설정 › 동작에서 끌 수 있습니다.
- **계속 열어 두는 탭을 고정하세요.** 탭을 마우스 오른쪽 버튼으로 클릭해 고정하세요. 고정된 탭은 앞쪽에 남고, "다른 탭 닫기"에도 살아남으며, 프로젝트별로 기억됩니다.
- **환경에 제대로 된 상세 보기가 생깁니다.** 환경을 열어 제목에서 이름을 바꾸고, 아이콘과 색을 설정하고, 하위 환경을 추가할 수 있습니다 — 그리고 오른쪽 클릭 메뉴로 이제 모든 변수와 하위 환경까지 포함해 환경을 복제합니다.

수정 사항:

- **코드 템플릿을 선택하면 라이브러리가 닫힙니다.** "사용"이 이제 곧바로 Code 페이지로 돌아갑니다.
- **문서 생성이 선택적 필드에서 더 이상 실패하지 않습니다.** 모델이나 매개변수가 "required"를 설정하지 않은 채 둔 디자인에서 문서를 생성해도 더 이상 템플릿 오류로 멈추지 않습니다.
- **열거형 삭제도 먼저 확인합니다.** 열거형도 모델·라우트와 동일한 확인을 받습니다.
- **사이드바가 선택을 드러냅니다.** '사이드바를 활성 탭과 동기화'가 켜져 있으면 모델·열거형·라우트를 선택하거나 만들 때 상위 항목이 펼쳐져 트리에서 계속 보입니다.
- **환경 버튼이 어떤 색에서도 읽기 쉽게 유지됩니다.** 이제 라벨이 실행 버튼처럼 환경 색 위에서 읽기 쉽도록 어두운 또는 밝은 텍스트로 바뀝니다.
- **가운데 클릭으로 열린 파일을 닫습니다.** 사이드바의 "열림" 목록에서 항목을 가운데 클릭하면 해당 탭이 닫힙니다 — 그리고 새 동작 설정으로 그 패널을 완전히 숨길 수 있습니다.
- **문서에서 시작할 때 더 명확한 문구.** 가져온 API의 문서에서 버튼이 이제 "이 문서에서 새 요청 만들기"로 표시됩니다.
- **Microsoft Store 버전에서 로그인이 작동합니다.** 로그인 후 브라우저가 돌려주는 사용자 지정 프로토콜 콜백이 이제 Store 패키지에 선언되어, 로그인이 시간 초과되지 않고 완료됩니다.

## v1.1.0

🎉 **이제 Restorm은 API 디자이너이기도 합니다.** API를 설계하고, 다섯 개의 프로토콜에 동시에 라이브 목으로 제공하고, 클라이언트를 생성하세요 — 앱을 벗어나지 않고, 모두 자신의 디스크에서.

- **비주얼 API 디자이너.** API를 직접 모델링하세요 — 모델, enum(이름 붙인 것 또는 인라인), 라우트, 파라미터, 이름 붙인 예제, 제약 조건, 태그와 사용 중단 표시 — 사양을 단 한 줄도 작성하지 않고.
- **한 번의 클릭으로, 5개 프로토콜에 동시에 목으로 제공.** 설계는 HTTP, GraphQL, SOAP, OData, gRPC로 동시에 응답하는 서버가 됩니다. 응답은 이름 붙인 예제(또는 모델에서 생성된 현실적인 데이터)에서 나오며, 제약 조건 검증, 지연 시뮬레이션, 스테이트풀 모드를 갖추고 있습니다.
- **바로 실행 가능한 클라이언트, 자동 생성.** 목이 실행되는 동안 Clients 섹션은 활성화된 각 프로토콜에 대해 목의 엔드포인트를 향한 실제 실행 가능한 요청을 만듭니다. 한 번의 클릭으로 요청을 열고 서버를 호출합니다 — API를 테스트하려고 다른 곳에 다시 가져올 필요가 더 이상 없습니다.
- 제공된 템플릿과 직접 만든 커스텀 템플릿을 사용해 설계로부터 **코드를 생성하세요**. 코드는 샌드박스에서 렌더링되며, 확인한 후에만 디스크에 기록됩니다. **디스크립터**(OpenAPI 등)도 **내보낼 수 있습니다**.
- **가져올 때 요청 본문이 미리 채워집니다**: GraphQL은 반환 타입의 스칼라 필드를 선택하고, gRPC는 중첩된 메시지를 펼칩니다 — 요청이 그대로 실행됩니다.

## v1.0.6

수정:

- **매우 큰 프로젝트가 이제 멈추는 대신 명확한 메시지와 함께 저장에 실패합니다.** 프로젝트가 한 번에 디스크에 기록하기에 너무 커지면(비정상적으로 큰 API 스키마를 가져온 뒤에 발생할 수 있습니다) Restorm이 충돌하거나 조용히 실패하지 않고 저장하기에 너무 크다고 분명히 알려줍니다.

## v1.0.5

**Cookie jar — 환경마다 하나의 쿠키 저장소를.**

- **모든 환경이 각자의 쿠키를 유지합니다.** 두 개의 환경에서 각각 개발 API와 프로덕션 API에 로그인해도 세션이 서로 섞이지 않습니다. 한 환경에서 수집한 쿠키는 오직 그 환경에서만 다시 전송됩니다. 이제 만료 시간, `Path`, `Domain` 및 하위 도메인, `Secure`, `HttpOnly`, `SameSite`가 버려지지 않고 그대로 적용됩니다.
- **Cookie jar를 소개합니다.** 새로운 워크벤치 탭 **보기 ▸ Cookie jar** 는 모든 환경의 쿠키를 도메인별로 묶어 접을 수 있는 창에 나열합니다. 값을 편집하고, 하나를 삭제하고, 도메인이나 저장소 전체를 비우거나, 직접 쿠키를 추가할 수 있습니다. 요청이 쿠키를 설정하면 실시간으로 새로 고쳐집니다.
- **각 요청이 무엇을 보내고 받았는지 확인하세요.** 이제 모든 요청에는 응답과 정보 옆에 **Cookies** 탭이 생겨, 호출과 함께 보낸 쿠키와 되돌려 받은 쿠키를 보여 줍니다. 최종 응답에는 결코 닿지 않는, 리다이렉트에서 설정된 쿠키까지 포함합니다. 기록에 있는 과거 응답에서도 이용할 수 있습니다.
- **쿠키 로그인이 그대로 동작합니다.** `Set-Cookie`를 반환하는 요청은 수집되어 이후의 보호된 호출에서 자동으로 다시 전송됩니다. 시나리오 실행 중에도 마찬가지이며, 모든 단계가 환경의 저장소를 공유합니다.
- **쿠키가 브라우저처럼 유지됩니다.** 만료 시간이 있는 쿠키는 프로젝트마다 저장되어 다시 열 때 불러오고, 세션 쿠키는 다시 시작할 때 사라집니다 — 브라우저와 똑같이 동작합니다.
- **REST 그 이상.** 이제 GraphQL, SOAP, OData, JSON-RPC, tRPC, SSE 모두 쿠키를 주고받고 저장하며, WebSocket은 연결 핸드셰이크에서 쿠키를 함께 전달합니다.
- **쿠키에 변수를 사용할 수 있습니다.** 직접 추가하는 쿠키에 `{{token}}`을 입력하면 요청이 나갈 때 활성 환경을 기준으로 값이 확인됩니다.

수정:

- **이제 자동 저장이 폴더 안의 환경까지 포함합니다.** 하위 환경을 추가하거나 이름을 바꾸면 자동 저장 모드에서 곧바로 저장됩니다 — 이미 디스크에 반영되어야 할 변경에 대해 더 이상 "닫기 전에 저장하시겠습니까?"라고 묻지 않습니다.

## v1.0.4

**한 번의 로그인 — 모든 창이 따라옵니다.**

- **이제 계정이 창 사이를 따라다닙니다.** 하나의 Restorm 창에서 로그인, 로그아웃 또는 플랜 변경을 하면 열려 있는 다른 모든 창이 즉시 이를 반영합니다 — 재시작도, 두 번째 로그인도 필요 없습니다. 또한 브라우저에서 로그인을 완료하면 여러 창이 열려 있어도 확인이 이를 요청한 창에 도착합니다.

수정:

- **Intel Mac에서 코드 노드가 다시 시작됩니다** — macOS Intel 빌드에 Apple Silicon용으로 컴파일된 esbuild 바이너리가 포함되어 있었습니다.
- **AppImage 런처의 "새 창" 동작이 다시 창을 열고**, .deb/.rpm 패키지가 설치하는 `restorm` 명령이 다시 작동합니다.
- **Windows 시작이 깔끔해졌습니다** — 이제 창이 앱 프로토콜을 통해 로드되며, 실행할 때마다 내부 오류 후 조용히 대체 방식으로 전환되지 않습니다.

## v1.0.3

**FUSE 없이도 CI에서 Restorm이 돌아갑니다.**

- **이제 `restorm-cli`가 CI 러너와 컨테이너에서 동작합니다.** Linux 빌드를 마운트하지 않고 풀어서 실행하므로, Ubuntu가 더는 제공하지 않는 FUSE가 필요 없습니다.

## v1.0.2

**CLI/CI 토큰을 앱에서 바로 관리하세요.**

- **Restorm에서 토큰을 만들고, 보고, 취소하세요** — Pro 및 Enterprise 사용자용, 제목 표시줄의 계정 버튼에서. 지금 작성 중인 파이프라인용 토큰 때문에 대시보드를 오갈 필요가 없습니다.
- **토큰에 유효 기간을 줄 수 있습니다.** 만들 때 7~365일 또는 기존처럼 만료 없음을 고르세요. 만료된 토큰은 취소된 토큰과 똑같이 거부됩니다.
- **조직에서 권한을 위임할 수 있습니다.** 관리자는 특정 구성원에게 토큰 생성을 허용하고, 별도로 감사 로그 열람도 허용할 수 있습니다. 관리자로 만들 필요가 없습니다.
- **이제 npm에서 Restorm을 바로 설치합니다.** `npm i -g restorm-cli` 후 `restorm`을 실행하면 Linux, macOS, Windows에서 설치 프로그램 없이 앱이 시작됩니다. 빌드는 한 번만 내려받아 공개된 체크섬으로 검증한 뒤 캐시에 보관하므로, 파이프라인이 작업마다 다시 내려받지 않습니다.

## v1.0.0

**Restorm 1.0 — 로컬 우선 API 클라이언트, 출시.**

Restorm은 모든 주요 프로토콜에서 API를 테스트하고 실행하기 위한 빠른 오프라인 우선 데스크톱 클라이언트입니다.

- **프로토콜**: REST/HTTP, GraphQL, gRPC, WebSocket, SSE, SOAP, OData, MQTT, AMQP, STOMP, Kafka, Redis, tRPC, JSON-RPC.
- **시나리오**: 요청을 시각적으로 연결하고 분기/반복하며, 값을 추출해 재사용하고, CI에서 헤드리스로 실행합니다.
- **환경 및 변수**: 어디서나 `{{handlebars}}`, 형식이 지정된 시크릿, 폴더별 환경.
- **가져오기/내보내기**: OpenAPI, Postman, Insomnia, HAR, WSDL, GraphQL SDL, OData EDMX, curl, 코드 내보내기.
- **Git 네이티브 프로젝트**: `.restorm` 프로젝트는 일반 파일입니다 — 버전을 관리하고, 비교하고, 앱 안에서 충돌을 해결하세요.
- **로컬 우선 및 비공개**: 모든 것이 사용자의 컴퓨터에서 실행되며, 아웃바운드 방화벽이 모든 외부 호출을 통제합니다.
- **크로스 플랫폼**: Windows, macOS, Linux (.deb/.rpm/AppImage) + npm.

무료 Community 에디션, 팀을 위한 Pro 및 Enterprise 제공.
