# Changelog

## v1.0.2

**CLI/CI 토큰을 앱에서 바로 관리하세요.**

- **Restorm에서 토큰을 만들고, 보고, 취소하세요** — Pro 및 Enterprise 사용자용, 제목 표시줄의 계정 버튼에서. 지금 작성 중인 파이프라인용 토큰 때문에 대시보드를 오갈 필요가 없습니다.
- **토큰에 유효 기간을 줄 수 있습니다.** 만들 때 7~365일 또는 기존처럼 만료 없음을 고르세요. 만료된 토큰은 취소된 토큰과 똑같이 거부됩니다.
- **조직에서 권한을 위임할 수 있습니다.** 관리자는 특정 구성원에게 토큰 생성을 허용하고, 별도로 감사 로그 열람도 허용할 수 있습니다. 관리자로 만들 필요가 없습니다.
- **이제 npm에서 Restorm을 바로 설치합니다.** `npm i -g restorm-cli` 후 `restorm`을 실행하면 Linux, macOS, Windows에서 설치 프로그램 없이 앱이 시작됩니다. 빌드는 한 번만 내려받아 공개된 체크섬으로 검증한 뒤 캐시에 보관하므로, 파이프라인이 작업마다 다시 내려받지 않습니다.

## v1.0.1

**첫 번째 패치 — 사이드바 이동, 탭 이름, 오류 보고서.**

- **사이드바에서 항목을 옮겨도 앱이 더 이상 망가지지 않습니다.** 미니 브라우저, 설정, MCP 로그가 열려 있으면 사이드바의 어떤 행을 끌어도 화면이 무너졌고 재시작해야만 복구됐습니다.

- **오류 보고서가 다시 전달됩니다.** 보고서 전송을 켜 두어도 1.0.0은 아무것도 보내지 않았습니다. 겪으신 오류가 저희에게 전혀 전달되지 않았습니다.
- **“코드 언어” 팁 일러스트에 로고가 다시 표시됩니다.**

## v1.0.0

**Restorm 1.0 — 로컬 우선 API 클라이언트, 출시.**

Restorm은 모든 주요 프로토콜에서 API를 테스트하고 실행하기 위한 빠른 오프라인 우선 데스크톱 클라이언트입니다.

- **프로토콜**: REST/HTTP, GraphQL, gRPC, WebSocket, SSE, SOAP, OData, MQTT, AMQP, STOMP, Kafka, Redis, tRPC, JSON-RPC.
- **시나리오**: 요청을 시각적으로 연결하고 분기/반복하며, 값을 추출해 재사용하고, CI에서 헤드리스로 실행합니다.
- **환경 및 변수**: 어디서나 `{{handlebars}}`, 형식이 지정된 시크릿, 폴더별 환경.
- **가져오기/내보내기**: OpenAPI, Postman, Insomnia, HAR, WSDL, GraphQL SDL, OData EDMX, curl, 코드 내보내기.
- **Git 네이티브 프로젝트**: `.restorm` 프로젝트는 일반 파일입니다 — 버전을 관리하고, 비교하고, 앱 안에서 충돌을 해결하세요.
- **로컬 우선 및 비공개**: 모든 것이 사용자의 컴퓨터에서 실행되며, 아웃바운드 방화벽이 모든 외부 호출을 통제합니다.
- **크로스 플랫폼**: Windows, macOS, Linux (.deb/.rpm/AppImage) + npm.

무료 Community 에디션, 팀을 위한 Pro 및 Enterprise 제공.
