# Changelog

## v1.1.4

**macOS で AI アシスタントを接続 — 確実になりました。**

- **修正: macOS の Claude Desktop と Cursor。** AI アシスタントを接続すると Restorm のツールは読み込まれるものの、Restorm を開いていても各呼び出しが「実行中のインスタンスがありません」で失敗していました。アプリとコネクタが別々の一時フォルダで互いを探していたためです。何がコネクタを起動したかにかかわらず、両者は確実に出会うようになりました。
- **イタリア語・ポーランド語・フィンランド語での丁寧な表現。** これら 3 言語で、インターフェースがほかと同様に丁寧な表現で語りかけるようになりました。

## v1.1.3

**AI アシスタントを Restorm に接続。**

- **ワンクリックで、アプリから。** ステータスバーの MCP メニューに「AI アシスタントに Restorm を追加」が加わりました。Claude Code、Claude Desktop、Cursor 向けの貼り付けるだけの設定に加え、ワンクリックの「Claude Code に追加」も利用できます。
- **あるいは 1 行で、どこからでも。** `npx -y restorm-mcp` で任意の MCP クライアントを実行中の Restorm に向けるだけで、ブリッジが自動で見つけます。コピーするポートやトークンはありません。
- **Claude Code 向けのプラグイン。** `/plugin marketplace add Monsieur-Dev/restorm` を実行し、`restorm` プラグインをインストールしてください。

[AI アシスタントの接続](https://restorm.app/en/docs/outils/mcp/)を参照してください。

## v1.1.2

**OpenAPI 3.2 に対応。**

- **OpenAPI 3.2 仕様のインポート。** `QUERY` メソッド、カスタム動詞（`additionalOperations`）、クエリ文字列パラメータ、ストリーミングメディアタイプが、すぐ実行できるリクエストとしてインポートされます。
- **インポートするファイルを参照。** インポートダイアログの参照ボタンでネイティブのファイル選択を開けます。パスの入力やドラッグはもう不要です。
- **大きな貼り付けは分割表示。** 複数行の仕様を貼り付けると、左にコードエディタ、右にプレビューが開き、間にドラッグ可能な仕切りが表示されます。
- **寛容なインポート。** 壊れた `$ref` がいくつかある仕様でも、可能なルートをすべてインポートし、スキップした内容を警告で表示します。

修正:

- 無効または到達できない仕様をインポートすると、クラッシュレポートのダイアログではなく分かりやすいメッセージが表示されます。
- クラッシュレポートの詳細ビューが再びスクロールできます。
- ダイアログの背景がぼかされなくなりました。

## v1.1.1

**API デザイナーがサイドバーから操作できるようになりました。**

- **モデル・enum・ルートがサイドバーに集約されました。** タブ内の 3 つのリストはなくなり、モデル（継承のネストつき）、enum、ルート（グループとそのルート）がサイドバーのツリーに直接並びます。右クリックで名前変更、サブモデルやサブグループの追加、ルートの複製、CRUD の生成、削除ができ、ドラッグで並べ替えや親の付け替えが可能です——設計の外へ出すことは決してありません。各ページには選択した項目の詳細だけが表示されます。
- **モデル・列挙型・ルートの全体像。** 各セクションのルートノードが配下をすべて一覧するようになり、モデルには**グラフ**タブが加わりました。継承と参照を描いたクラス図です。列挙型は値を名前のすぐ横に表示します。
- **名前の変更は常に同じ場所で。** モデル・列挙型・ルートは大きなタイトル（鉛筆）から名前を変更でき、名前が空のときは **「<名称未設定>」** と表示されるので鉛筆に常に手が届きます。名前がページに二重表示されることはなくなりました。
- **検証エラーが対象を指し示します。** 何か問題があるとき（モデルと列挙型が同じ名前、既に存在しないものへの参照など）、そのモデル・列挙型・ルートの上部の注記が説明します。
- **完全なパンくずリスト。** 経路がサイドバーの階層全体（フォルダ › デザイン › セクション › グループ › 項目）を反映し、各セグメントをクリックできます。
- **複数選択して一括削除。** 複数のモデル・列挙型・ルートを選び、確認のうえ一度に削除できます。
- **コードテンプレートのソースをワンクリックでコピー／オープン。** 「</> Code」ページでテンプレートにマウスを重ねると、その URL やパスをコピーするボタンと、開くボタンが現れます——ブラウザでリポジトリを、ローカルテンプレートならディスク上のフォルダーを開きます。
- **新しいルートに名前が付くようになりました。** ゼロから作成したルートに既定の名前が付くため、すぐに名前を変更できます。
- **エディターのようなプレビュータブ。** シングルクリックで項目が再利用可能な**プレビュー**タブで開くようになりました（名前はイタリック表示）。別の項目をクリックすると、新しいタブを積み重ねる代わりに同じタブが再利用されます。ダブルクリック、何らかの編集、またはリクエストの実行で恒久的に開いたままになります。設定 › 動作 でオフにできます。
- **開いておくタブをピン留め。** タブを右クリックしてピン留めできます。ピン留めしたタブは先頭に残り、「他を閉じる」でも消えず、プロジェクトごとに記憶されます。
- **環境に本格的な詳細ビュー。** 環境を開くと、タイトルから名前を変更したり、アイコンと色を設定したり、サブ環境を追加したりできます——さらに右クリックメニューで、変数とサブ環境をすべて含めて環境を複製できるようになりました。

修正:

- **コードテンプレートを選ぶとライブラリが閉じます。** 「使用」で Code ページにそのまま戻ります。
- **ドキュメント生成が省略可能なフィールドで失敗しなくなりました。** モデルやパラメーターで「required」が未設定の設計からドキュメントを生成しても、テンプレートエラーで止まらなくなりました。
- **列挙型の削除は先に確認します。** 列挙型もモデルやルートと同じ確認が表示されます。
- **サイドバーが選択を明らかにします。** 「サイドバーをアクティブなタブと同期」を有効にすると、モデル・列挙型・ルートを選択または作成したときに親が展開され、ツリー内で見えるようになります。
- **環境ボタンがどんな色でも読みやすいままに。** ラベルが環境の色に対して読みやすいよう、実行ボタンと同じく明色または暗色のテキストに切り替わるようになりました。
- **中クリックで開いているファイルを閉じる。** サイドバーの「開いているもの」リストの項目を中クリックすると、そのタブが閉じます——さらに新しい「動作」設定でそのパネルをまるごと非表示にできます。
- **ドキュメントから始めるときの文言をより明確に。** インポートした API のドキュメントで、ボタンの表記が「このドキュメントから新しいリクエストを作成」になりました。
- **Microsoft Store 版でサインインできるように。** ログイン後にブラウザーが返すカスタムプロトコルのコールバックが Store パッケージに宣言されるようになり、サインインがタイムアウトせず完了します。

## v1.1.0

🎉 **Restorm は今や API デザイナーでもあります。** API を設計し、5 つのプロトコルで同時にライブモックとして提供し、そのクライアントを生成する — すべてアプリの中で、すべて自分のディスク上で。

- **ビジュアルな API デザイナー。** API を手作業でモデリングします — モデル、enum（名前付きまたはインライン）、ルート、パラメーター、名前付きの例、制約、タグと非推奨 — 仕様を一行も書くことなく。
- **ワンクリックで、5 つのプロトコルに同時にモックとして提供。** 設計は、HTTP、GraphQL、SOAP、OData、gRPC で同時に応答するサーバーになります。レスポンスは名前付きの例（またはモデルから生成された現実的なデータ）から返され、制約の検証、レイテンシーのシミュレート、ステートフルモードを備えています。
- **すぐに実行できるクライアントを自動生成。** モックの実行中、Clients セクションが、有効化された各プロトコルに対して、モックのエンドポイントに向けた実際に実行可能なリクエストを作成します。ワンクリックでリクエストを開いてサーバーを叩けます — テストのために API を別の場所へ再インポートする必要はもうありません。
- 用意されたテンプレートとご自身のカスタムテンプレートを使って、設計から**コードを生成**します。コードはサンドボックス内でレンダリングされ、確認した後にのみディスクへ書き込まれます。**ディスクリプター**（OpenAPI ほか）も**エクスポート**できます。
- **インポート時、リクエストボディが事前入力されます**。GraphQL は戻り値の型のスカラーフィールドを選択し、gRPC はネストされたメッセージを展開します — リクエストはそのまま実行できます。

## v1.0.6

修正:

- **非常に大きなプロジェクトの保存が、フリーズせず明確なメッセージで失敗するようになりました。** プロジェクトが大きくなりすぎて一度にディスクへ書き込めない場合（異常に大きな API スキーマをインポートした後などに起こり得ます）、Restorm はクラッシュしたり黙って失敗したりせず、保存するには大きすぎることをはっきりと知らせます。
- **舞台裏でのエラー報告がより明確になりました。** 「名前を付けて保存」ダイアログのキャンセルがエラーとして記録されなくなり、インポートの失敗が実際の原因を報告するようになりました。これにより本当の問題を見つけて修正しやすくなります。

## v1.0.5

**Cookie jar — 環境ごとに 1 つの Cookie 保管庫。**

- **すべての環境が自分専用の Cookie を保持します。** 2 つの環境から開発 API と本番 API にそれぞれサインインしても、セッションが混ざることはありません。一方で取得した Cookie は、その環境でのみ送り返されます。有効期限、`Path`、`Domain` とサブドメイン、`Secure`、`HttpOnly`、`SameSite` は破棄されず、きちんと尊重されるようになりました。
- **Cookie jar のご紹介。** 新しいワークベンチタブ **表示 ▸ Cookie jar** は、すべての環境の Cookie をドメインごとにまとめ、折りたたみ可能なペインで一覧表示します。値を編集したり、1 つ削除したり、ドメイン単位または保管庫全体をクリアしたり、手動で Cookie を追加したりできます。リクエストが Cookie を設定すると、リアルタイムで更新されます。
- **各リクエストが送受信した内容を確認できます。** すべてのリクエストに、レスポンスや情報の隣に **Cookies** タブが追加され、呼び出しとともに送信された Cookie と、受信した Cookie を表示します。最終的なレスポンスには決して現れない、リダイレクトで設定された Cookie も含まれます。履歴にある過去のレスポンスでも確認できます。
- **Cookie ログインがそのまま機能します。** `Set-Cookie` を返すリクエストは取得され、その後に続く保護された呼び出しで自動的に再送されます。シナリオの実行中も同様で、各ステップが環境の保管庫を共有します。
- **Cookie はブラウザーのように永続化されます。** 有効期限のある Cookie はプロジェクトごとに保存され、再び開いたときに再読み込みされます。セッション Cookie は再起動時に破棄されます。まさにブラウザーと同じ動作です。
- **REST だけではありません。** GraphQL、SOAP、OData、JSON-RPC、tRPC、SSE がすべて Cookie を送受信・保存できるようになり、WebSocket は接続ハンドシェイク時に Cookie を運びます。
- **Cookie で変数を使えます。** 手動で追加する Cookie に `{{token}}` と入力すると、リクエスト送信時にアクティブな環境をもとに解決されます。

修正:

- **オートセーブがフォルダー内の環境にも対応しました。** サブ環境の追加や名前の変更が、オートセーブモードで即座に保存されるようになりました。すでにディスクに保存されるべき変更に対して「閉じる前に保存しますか？」と尋ねられることはなくなりました。

## v1.0.4

- **アカウントがウィンドウをまたいで同期されるようになりました。** 1つのRestormウィンドウでサインイン・サインアウト・プラン変更を行うと、開いている他のすべてのウィンドウが即座にそれを反映します — 再起動も再ログインも不要です。また、ブラウザでサインインを完了すると、複数のウィンドウを開いていても、確認がそれを要求したウィンドウに届くようになりました。

修正:

- **Intel搭載Macでコードノードが再び起動します** — macOS Intel版にApple Silicon用にコンパイルされたesbuildバイナリが含まれていました。
- **AppImageランチャーの「新しいウィンドウ」アクションが再びウィンドウを開き**、.deb/.rpmパッケージがインストールする`restorm`コマンドが再び動作します。
- **Windowsでの起動がクリーンになりました** — ウィンドウはアプリプロトコル経由で読み込まれ、起動のたびに内部エラー後のサイレントなフォールバックが発生しなくなりました。

## v1.0.2

**CLI/CI トークンを、アプリを離れずに管理。**

- **Restorm から作成・確認・失効できます** — Pro および Enterprise のご利用者向け、タイトルバーのアカウントボタンから。いま書いているパイプライン用のトークンのためにダッシュボードへ往復する必要はもうありません。
- **トークンに有効期限を設定できます。** 作成時に 7〜365 日、または従来どおり無期限を選べます。期限切れのトークンは失効済みと同じく拒否されます。
- **組織で権限を委譲できます。** 管理者は特定のメンバーにトークン作成を許可でき、監査ログの閲覧も別々に許可できます。管理者にする必要はありません。
- **npm から Restorm 本体をインストールできるようになりました。** `npm i -g restorm-cli` のあとに `restorm` と入力すれば、Linux・macOS・Windows のいずれでもインストーラーを経由せずにアプリが起動します。ビルドのダウンロードは一度だけで、公開されたチェックサムで検証してからキャッシュに保存するため、パイプラインがジョブごとに取得し直すことはありません。

## v1.0.0

**Restorm 1.0 — local-first の API クライアント、リリース。**

Restorm は、主要なあらゆるプロトコルで API をテスト・実行するための、高速でオフラインファーストのデスクトップクライアントです。

- **プロトコル**: REST/HTTP、GraphQL、gRPC、WebSocket、SSE、SOAP、OData、MQTT、AMQP、STOMP、Kafka、Redis、tRPC、JSON-RPC。
- **シナリオ**: リクエストを視覚的に連結し、分岐・ループ、値の抽出と再利用、CI でのヘッドレス実行が可能です。
- **環境と変数**: どこでも `{{handlebars}}`、型付きのシークレット、フォルダーごとの環境。
- **インポート/エクスポート**: OpenAPI、Postman、Insomnia、HAR、WSDL、GraphQL SDL、OData EDMX、curl、コードのエクスポート。
- **Git ネイティブなプロジェクト**: `.restorm` プロジェクトはただのファイルです。バージョン管理し、差分を取り、アプリ内で競合を解決できます。
- **ローカルファーストでプライベート**: すべてが自分のマシン上で動作し、送信ファイアウォールがすべての外部呼び出しを制御します。
- **クロスプラットフォーム**: Windows、macOS、Linux (.deb/.rpm/AppImage) + npm。

無料の Community エディション、チーム向けの Pro と Enterprise もあります。
