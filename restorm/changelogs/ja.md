# Changelog

## v1.0.4

**一度のサインインで、すべてのウィンドウに反映。**

- **アカウントがウィンドウをまたいで同期されるようになりました。** 1つのRestormウィンドウでサインイン・サインアウト・プラン変更を行うと、開いている他のすべてのウィンドウが即座にそれを反映します — 再起動も再ログインも不要です。また、ブラウザでサインインを完了すると、複数のウィンドウを開いていても、確認がそれを要求したウィンドウに届くようになりました。

修正:

- **Intel搭載Macでコードノードが再び起動します** — macOS Intel版にApple Silicon用にコンパイルされたesbuildバイナリが含まれていました。
- **AppImageランチャーの「新しいウィンドウ」アクションが再びウィンドウを開き**、.deb/.rpmパッケージがインストールする`restorm`コマンドが再び動作します。
- **Windowsでの起動がクリーンになりました** — ウィンドウはアプリプロトコル経由で読み込まれ、起動のたびに内部エラー後のサイレントなフォールバックが発生しなくなりました。

## v1.0.3

**FUSE なしで、CI でも Restorm が動きます。**

- **`restorm-cli` が CI ランナーとコンテナで動くようになりました。** Linux ビルドをマウントせず展開するようにしたため、Ubuntu が提供をやめた FUSE はもう必要ありません。

## v1.0.2

**CLI/CI トークンを、アプリを離れずに管理。**

- **Restorm から作成・確認・失効できます** — Pro および Enterprise のご利用者向け、タイトルバーのアカウントボタンから。いま書いているパイプライン用のトークンのためにダッシュボードへ往復する必要はもうありません。
- **トークンに有効期限を設定できます。** 作成時に 7〜365 日、または従来どおり無期限を選べます。期限切れのトークンは失効済みと同じく拒否されます。
- **組織で権限を委譲できます。** 管理者は特定のメンバーにトークン作成を許可でき、監査ログの閲覧も別々に許可できます。管理者にする必要はありません。
- **npm から Restorm 本体をインストールできるようになりました。** `npm i -g restorm-cli` のあとに `restorm` と入力すれば、Linux・macOS・Windows のいずれでもインストーラーを経由せずにアプリが起動します。ビルドのダウンロードは一度だけで、公開されたチェックサムで検証してからキャッシュに保存するため、パイプラインがジョブごとに取得し直すことはありません。

## v1.0.1

**最初のパッチ — サイドバーの移動、タブ名、クラッシュレポート。**

- **サイドバーで項目を移動してもアプリが壊れなくなりました。** ミニブラウザー、設定、MCP ログのいずれかを開いた状態でサイドバーの行をドラッグすると画面が崩れ、再起動しないと戻りませんでした。
- **項目の名前を変更すると、開いているすべてのタブに反映されます。** 分割ペイン内のタブや、あらゆるリクエスト種別（gRPC、GraphQL、Redis など）のタブも対象です。これまでは開き直すまで古い名前のままでした。
- **クラッシュレポートが再び届くようになりました。** レポート送信を有効にしていても、1.0.0 は何も送信していませんでした。発生したクラッシュは私たちに何も伝えていませんでした。
- **「コード言語」のヒント画像にロゴが再表示されます。**

## v1.0.0

**Restorm 1.0 — local-first の API クライアント、リリース。**

Restorm は、主要なあらゆるプロトコルで API をテスト・実行するための、高速でオフラインファーストのデスクトップクライアントです。

- **プロトコル**: REST/HTTP、GraphQL、gRPC、WebSocket、SSE、SOAP、OData、MQTT、AMQP、STOMP、Kafka、Redis、tRPC、JSON-RPC。
- **シナリオ**: リクエストを視覚的に連結し、分岐・ループ、値の抽出と再利用、CI でのヘッドレス実行が可能です。
- **環境と変数**: どこでも `{{handlebars}}`、型付きのシークレット、フォルダーごとの環境。
- **インポート/エクスポート**: OpenAPI、Postman、Insomnia、HAR、WSDL、GraphQL SDL、OData EDMX、curl、コードのエクスポート。
- **Git ネイティブなプロジェクト**: `.restorm` プロジェクトはただのファイルです。バージョン管理し、差分を取り、アプリ内で競合を解決できます。
- **ローカルファーストでプライベート**: すべてが自分のマシン上で動作し、送信ファイアウォールがすべての外部呼び出しを制御します。
- **クロスプラットフォーム**: Windows、macOS、Linux (.deb/.rpm/AppImage) + npm。

無料の Community エディション、チーム向けの Pro と Enterprise もあります。
